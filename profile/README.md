# Sideband

Sideband is an open-source communication platform for communities you can host yourself.

Message friends, organize channels, hang out in voice, share your screen, and use video — all from one desktop app.

[Download Sideband](https://sideband.chat) · [Self-hosting](https://sideband.chat/#self-hosting)
